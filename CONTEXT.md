# CONTEXT.md — ILDIS Domain Glossary

## Domain

ILDIS (Indonesian Law Documentation Information System) manages legal document metadata for Indonesia's JDIHN (Jaringan Dokumentasi dan Informasi Hukum Nasional — National Law Documentation and Information Network).

## Core Entities

### Document
The central entity. All legal materials — regulations, monographs, articles, court decisions — live in the `document` table, discriminated by `tipe_dokumen`.
- **Peraturan** — Regulation (government rule, law, decree)
- **Monografi** — Monograph (academic/legal text)
- **Artikel** — Article (shorter legal writing)
- **Putusan** — Court decision
- **Dokumen JDIH** — JDIHN-published document

### Document Lifecycle
A Document moves through states: draft → published → verified. Key transitions:
- **Status Transition** — Changing legal standing (berlaku/tidak berlaku, dicabut/mencabut, diubah/mengubah)
- **Verification** — Librarian review before public visibility (`is_publish` flag)
- **Attachment Management** — PDF/document file uploads (`DataLampiran`)

### Cataloging
Bibliographic metadata attached to Documents:
- **Subject Tagging** (`DataSubyek`) — Hierarchical legal subject classification
- **Author Tracking** (`DataPengarang`, TEU) — Persons or bodies responsible for the document
- **Status History** (`DataStatus`) — Audit trail of document state changes

> **Deprecated**: Physical copy tracking (`Eksemplar`) and circulation (loan/return/fines) are deprecated per ADR-0002 and will not be migrated to the new stack.

### Community
Public-facing interactions:
- **Masukan Masyarakat** — Public feedback/suggestions
- **Buku Tamu** — Visitor log/contact form
- **Feed Generation** — Public JSON/RSS feeds for external portal consumption

### Access Control
RBAC with institution-scoped roles:
- **Pustakawan** — Librarian (document CRUD)
- **Koordinator Pustakawan** — Head librarian (verification, reports)
- **Peraturan** — Regulation specialist
- **Superadmin** — Full access

## Key Terms

- **JDIHN** — The national network this system feeds into
- **TEU** — Tanggung Jawab Hukum (legal accountability / author body)
- **Lampiran** — Attachment/file upload
- **Subyek** — Subject/topic classification
- **Eksemplar** — Physical copy/exemplar
- **Pembentukan PUU** — Legislation formation process
- **Hasil Uji Materi** — Material test results (constitutional review)
- **Pencabutan** — Revocation (of a regulation by another)
- **Penggantian** — Replacement/amendment

## Existing Architecture Decisions

- Yii2 Advanced Template with backend/frontend/common/console tiers
- ActiveRecord for all database access
- RBAC permissions stored in database (`auth_item`, `auth_assignment` tables)
- Document types discriminated by string in a single table (not separate tables)
- Public data exposed via JSON feed files generated by console commands
